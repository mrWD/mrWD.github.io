AI Prompt Suggester

A 💡 button inside the AI chats you already use. Open it, search a prompt, fill in the blanks where they sit in the text, and send — without keeping a prompt library in a notes app somewhere else.

What it does

  • 🔍

    Search as you type

    Filter the whole prompt library instantly, across prompt text and categories, with matches highlighted. Ctrl/Cmd+F jumps to the search box.

  • 🎯

    Blanks where they belong

    Placeholders like {1} and {2} become input fields inline, right in the prompt text — so you see the finished prompt as you fill it in.

  • ⌨️

    Keyboard all the way

    Arrows move between results and between inputs, Enter applies the prompt to the chat, Esc backs out.

  • 📋

    Copy instead of send

    Ctrl/Cmd+C copies the prompt in its current state, with your values already substituted.

  • 🌍

    Seven interface languages

    English, German, Russian, Italian, French, Spanish and Chinese.

  • 🎨

    Stays out of the way

    It follows your system theme and lives behind one button, rather than taking over the chat you're using.

Installing it

Chrome, Edge, Opera

Install from the Chrome Web Store.

Or clone the repo, open chrome://extensions/, turn on Developer mode and use Load unpacked.

Firefox

Install from Firefox Add-ons.

Or load it temporarily from about:debugging during development.

Then open any supported chat and look for the 💡 button next to the input.
